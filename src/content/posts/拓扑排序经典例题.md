# 拓扑排序经典题：判断序列是否确定（[洛谷P1094](https://www.luogu.com.cn/problem/P1347)）

## 题目简介

给出若干个大小关系：

```
A < B
```

表示元素 A 在最终排序中应该排在 B 前面。

现在需要判断：

1. 是否存在矛盾（例如）：

```
A < B
B < C
C < A
```

形成环。

2. 是否已经可以唯一确定整个排序。

3. 如果可以，输出第几个关系加入后确定的排序。

---

## 建模：把大小关系转换成有向图

对于：

```
A < B
```

建立一条有向边：

```
A → B
```

因为：

- A 必须先出现
- B 必须后出现

所以最终排序就是这个图的拓扑序。

例如：

关系：

```
A < B
B < C
```

对应：

```
A → B → C
```

拓扑排序结果：

```
ABC
```

---

## 思路

每加入一条关系，就重新进行一次拓扑排序。

拓扑排序过程中：

- 如果所有点都能被取出，并且每次只有一个入度为 0 的点：

说明排序唯一。

- 如果出现环：

说明矛盾。

- 如果某一步有多个入度为 0 的点：

说明当前存在多个选择，排序不唯一。

---

## 坑点 1：判断多个排列不能优先于判断矛盾



```cpp
while(!q.empty()){
    if(q.size()>1)
        return false;
}
```

这样写是有问题的。

因为有多个入度为 0 的点，不代表一定没有环。


正确做法：

先完整进行拓扑排序。

如果：

```cpp
排序出来的点数 != n
```

说明存在环。

只有确定没有环后，再判断是否唯一。


---

## 坑点 2：拓扑排序时不能修改原入度

错误：

```cpp
in[v]--;
```

因为 `in` 保存的是原图信息。

而这道题需要：

每加入一条边，都重新判断一次。

如果第一次拓扑排序修改了 `in`：

第二次判断时入度已经被破坏。

正确：

```cpp
int d[30];

for(int i=0;i<n;i++)
    d[i]=in[i];
```

使用 `d` 进行拓扑。

---

## 坑点 3：必须在线判断

题目问的是：第几个关系加入后确定答案。


所以不能：

```
读完所有关系
↓
一次拓扑
```

而应该：

```
加入一条关系
↓
拓扑判断
↓
是否结束
```

代码：

```cpp

#include<bits/stdc++.h>
using namespace std;
#define int long long
#define all(x) x.begin(),x.end()
#define YES cout<<"YES\n"
#define NO cout<<"NO\n"
#define cfs cout<<fixed<<setprecision
typedef pair<int,int> PII;
const int N=1e5+10;
const int INF=1e18;

vector<char> e[30];
int in[30];
int n,m;
string s;

// 拓扑排序
// 返回：
// 1  表示可以唯一确定排序
// 0  表示存在多个可能的排序
// -1 表示存在环，关系矛盾
int tuopu(){
    s="";
    // 复制入度数组
    // 因为拓扑排序会修改入度，不能直接修改原数组
    int d[30];
    for(int i=0;i<n;i++) d[i]=in[i];

    queue<int>q;
    // 将所有当前入度为0的点加入队列
    // 它们表示当前可以放在最前面的元素
    for(int i=0;i<n;i++){
        if(d[i]==0) q.push(i);
    }

    bool flag=1;   // 标记拓扑序是否唯一
    while(!q.empty()){
        // 如果同时存在多个入度为0的点
        // 说明当前有多个选择，无法唯一确定
        if(q.size()>1) flag=0;
        int u=q.front();
        q.pop();
        // 加入当前拓扑序
        s+=char(u+'A');
        // 删除u的所有出边
        // 表示u已经完成，不再限制后面的点
        for(char v:e[u]){
            // 删除一条边，后继节点入度减1
            d[v-'A']--;
            // 当某个点入度变为0
            // 说明它所有前驱都已经处理完
            if(d[v-'A']==0) q.push(v-'A');
        }
    }

    // 如果没有处理完所有点
    // 说明存在环
    if((int)s.size()!=n) return -1;
    // 无环情况下判断是否唯一
    if(flag) return 1;
    return 0;

}



void solve(){
    cin>>n>>m;
    // 一条一条加入关系
    // 因为题目要求找到第几个关系后确定答案
    for(int i=1;i<=m;i++){
        char u,c,v;
        cin>>u>>c>>v;
        e[u-'A'].push_back(v);
        in[v-'A']++;
        // 每加入一条关系，都重新判断当前状态
        int ans=tuopu();

        // 已经确定唯一排序
        if(ans==1){
            cout<<"Sorted sequence determined after "<<i<<" relations: "<<s<<".";
            return;
        }
        // 发现环，说明关系矛盾
        if(ans==-1){
            cout<<"Inconsistency found after "<<i<<" relations.";
            return;
        }
    }
    // 所有关系加入后仍然无法确定
    cout<<"Sorted sequence cannot be determined.";

    return;
}

signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int T=1;
    //cin>>T;
    while(T--) solve();
    return 0;
}

```
