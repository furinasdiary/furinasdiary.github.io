# P3400 仓鼠窝 题解

题目链接：[洛谷P3400](https://www.luogu.com.cn/problem/P3400)


## 一、题目大意

给定一个 $n\times m$ 的 01 矩阵，`1` 代表完好格子，`0` 代表破损格子。

求：**矩阵中所有不包含任何破损格子的子矩阵总数量**。

子矩阵定义：任意连续行、连续列构成的矩形区域。

### 样例说明

输入：

```Plain Text
3 4
1 1 1 1
1 0 1 1
1 1 0 1
```

输出：`26`

## 二、解题思路

本题是经典的**全1子矩阵计数**模板题，核心采用 **悬线法 \+ 单调栈** 高效求解，时间复杂度 $O(nm)$，可以轻松通过 $3000\times3000$ 的极限数据。

### 1\. 悬线高度预处理

定义 $h[i][j]$：以第 $i$ 行第 $j$ 列为底部，向上连续完好格子的高度（悬线高度）。

- 若当前格子为`1`：$h[i][j] = h[i-1][j] + 1$

- 若当前格子为 `0`：$h[i][j] = 0$（断开悬线）

每一行的$h$ 数组，可等价为「柱状图」，问题转化为：**统计每行柱状图中所有合法矩形数量**。

### 2\. 单调栈求左右边界

对每一行的柱状图，用单调栈预处理每个位置 $j$ 的两个边界：

- $l[j]$：左侧第一个高度小于当前高度的位置

- $r[j]$：右侧第一个高度小于等于当前高度的位置（去重防重复计数）

### 3\. 统计子矩阵数量

对于每个位置 $(i,j)$，以该位置为最低点的合法矩形数量为：

$cnt = (j-l[j]) \times (r[j]-j) \times h[i][j]$

累加所有位置的数量，即为最终答案。

## 三、AC 代码


```Plain Text
#include<bits/stdc++.h>
using namespace std;

const int N = 3010;
// h[i][j] 表示(i,j)位置向上连续1的高度
int h[N][N];

void solve(){
    int n, m;
    cin >> n >> m;
    // 预处理悬线高度
    for(int i = 1; i <= n; i++){
        for(int j = 1; j <= m; j++){
            char c;
            cin >> c;
            if(c == '1') h[i][j] = h[i-1][j] + 1;
            else h[i][j] = 0;
        }
    }

    long long ans = 0;
    // 逐行单调栈计算
    for(int i = 1; i <= n; i++){
        stack<int> st;
        vector<int> l(m + 1, 0);
        vector<int> r(m + 1, 0);

        // 找左边界：第一个严格小于当前高度的位置
        for(int j = 1; j <= m; j++){
            while(!st.empty() && h[i][j] <= h[i][st.top()]) st.pop();
            l[j] = st.empty() ? 0 : st.top();
            st.push(j);
        }

        // 清空栈，找右边界：第一个严格小于当前高度的位置
        while(!st.empty()) st.pop();
        for(int j = m; j >= 1; j--){
            while(!st.empty() && h[i][j] < h[i][st.top()]) st.pop();
            r[j] = st.empty() ? m + 1 : st.top();
            st.push(j);
        }

        // 累加当前行所有合法子矩阵数量
        for(int j = 1; j <= m; j++){
            ans += 1LL * (j - l[j]) * (r[j] - j) * h[i][j];
        }
    }
    cout << ans << endl;
}

signed main(){
    // 快读优化，适配大数据
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    solve();
    return 0;
}
```

## 四、复杂度分析

- **时间复杂度**：$O(nm)$，每个元素入栈、出栈仅一次，无多余遍历

- **空间复杂度**：$O(nm)$，可进一步滚动数组优化为 $O(m)$

## 五、核心细节总结

1. 左右边界判断条件**不严格对称**（一边 \<=、一边 \<），避免重复统计矩形；

2. 答案必须开 `long long`，大数据范围会爆 int；

3. 清空栈必须彻底，防止上一行数据干扰当前行计算；
