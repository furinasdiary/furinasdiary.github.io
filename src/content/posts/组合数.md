# 组合数模板（预处理阶乘+逆元）
## 算法介绍
预处理阶乘与阶乘逆元，快速求解组合数 $C(n,m) \bmod p$，要求模数 $p$ 为质数。
利用费马小定理求逆元，单次查询组合数时间复杂度 $O(1)$。

### 核心原理
1. 阶乘递推：$\text{fact}[i] = \text{fact}[i-1] \times i \pmod{\text{p}}$
2. 费马小定理：若 $\text{p}$ 是质数，则 $a^{\text{p}-2}\equiv a^{-1}\pmod{\text{p}}$
3. 逆元阶乘倒推：$\text{invfact}[i]=\text{invfact}[i+1]\times(i+1)\pmod{\text{p}}$
4. 组合数公式：
$$
C(n,m)=\frac{n!}{m!\cdot(n-m)!} \equiv \text{fact}[n]\times\text{invfact}[m]\times\text{invfact}[n-m] \pmod{\text{p}}
$$

## AC代码
```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define all(x) x.begin(),x.end()
#define YES cout<<"YES\n"
#define NO cout<<"NO\n"
#define cfs cout<<fixed<<setprecision
typedef pair<int,int> PII;
const int N=2e6+10;
const int INF=1e18;
const int mod=1e9+7;

int fact[N],invfact[N];//阶乘数组fact与逆元阶乘数组invfact

int qpow(int a,int x){
    int ans=1;
    while(x){
        if(x&1) ans=ans*a%mod;
        a=a*a%mod;
        x>>=1;
    }
    return ans;
}

void init(){
    //预处理阶乘数组fact与逆元阶乘数组invfact，用于组合数计算
    fact[0]=1;
    //递推计算0~N-1的阶乘，全程取模防止溢出
    for(int i=1;i<N;i++){
        fact[i]=fact[i-1]*i%mod;
    }
    //费马小定理求最大下标阶乘的逆元，mod为质数
    invfact[N-1]=qpow(fact[N-1],mod-2);
    //倒序递推所有阶乘逆元，利用inv[i]=inv[i+1]*(i+1)%mod公式
    for(int i=N-2;i>=0;i--){
        invfact[i]=invfact[i+1]*(i+1)%mod;
    }
}

int c(int n,int m){
    //组合数公式c(n,m)=n!/(m!*(n-m)!)，利用预处理逆元阶乘转化为乘法取模
    return fact[n]*invfact[m]%mod*invfact[n-m]%mod;
}

void solve(){
    init();
    int n,m;
    cin>>n>>m;
    cout<<c(n,m)%mod;
}

signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int T=1;
    //cin>>T;
    while(T--) solve();
    return 0;
}
```
