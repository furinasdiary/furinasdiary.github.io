# 洛谷P1966 火柴排队 题解

题目链接: [洛谷P1966](https://www.luogu.com.cn/problem/P1966)


## 题目描述

涵涵有两盒火柴，每盒装有 $n$ 根火柴，每根火柴都有一个高度。现在将每盒中的火柴各自排成一列，同一列火柴的高度互不相同。两列火柴之间的距离定义为：

$$
\sum_{i=1}^{n}(a_i-b_i)^2
$$

其中 $a_i$ 表示第一列火柴中第 $i$ 根火柴的高度，$b_i$ 表示第二列火柴中第 $i$ 根火柴的高度。

每列火柴中相邻两根火柴的位置都可以交换，请你通过交换使得两列火柴之间的距离最小。请问得到这个最小的距离，最少需要交换多少次？如果这个数字太大，请输出这个最小交换次数对 $10^8-3$ 取模的结果。

## 思路

### 1. 什么时候距离最小？

根据排序不等式，当两个序列按相同的大小顺序一一对应时，$\sum (a_i-b_i)^2$ 最小。  
也就是说，第一列中第 $k$ 小的火柴应该和第二列中第 $k$ 小的火柴放在同一位置。

### 2. 转化为逆序对问题

将两列火柴分别离散化，得到每个火柴在各自列中的排名。  
设第一列中排名为 $x$ 的火柴原位置为 $pos[x]$。  
对于第二列，按原顺序遍历每个位置 $i$，设其排名为 $b_i$，则它应该匹配第一列中排名为 $b_i$ 的火柴，即第一列的位置 $pos[b_i]$。  
于是构造数组 $p$，其中 $p_i = pos[b_i]$。

现在问题变成：将排列 $p$ 通过相邻交换变成升序 $1,2,\dots,n$ 的最少交换次数。  
而相邻交换一次最多减少一个逆序对，所以最少交换次数就是 $p$ 的逆序对数。

### 3. 树状数组求逆序对

从右向左扫描数组 $p$，用树状数组维护已经出现过的数字。  
对于当前数字 $x$，查询树状数组中比 $x$ 小的数字个数，累加到答案中，然后把 $x$ 加入树状数组。  
由于答案需要对 $10^8-3$ 取模，累加时取模即可。

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define all(x) x.begin(),x.end()
#define YES cout<<"YES\n"
#define NO cout<<"NO\n"
#define cfs cout<<fixed<<setprecision
typedef pair<int,int> PII;
const int N=1e5+10;          // 最大火柴数
const int mod=1e8-3;         // 取模的数

int a[N];                    // 第一列火柴（离散化后）
int b[N];                    // 第二列火柴（离散化后）
int pos[N];                  // pos[x] 表示第一列中排名为 x 的火柴原位置
int tr[N];                   // 树状数组
int n;

// 树状数组基本操作
int lowbit(int x){
    return x&-x;
}

// 在位置 x 加上 v
void add(int x,int v){
    for(;x<=n;x+=lowbit(x)){
        tr[x]+=v;
    }
}

// 查询前缀和：1 到 x 的和（对 mod 取模）
int get(int x){
    int ans=0;
    for(;x;x-=lowbit(x)){
        ans = (ans + tr[x]) % mod;
    }
    return ans % mod;
}

void solve(){
    cin>>n;
    vector<int> c;           // 用于离散化的临时数组

    // 读入第一列火柴并离散化
    for(int i=1;i<=n;i++){
        cin>>a[i];
        c.push_back(a[i]);
    }
    sort(all(c));
    c.erase(unique(all(c)),c.end());
    for(int i=1;i<=n;i++){
        // 将 a[i] 映射为它在所有数中的排名（从 1 开始）
        a[i]=lower_bound(all(c),a[i])-c.begin()+1;
        // 记录第一列中排名为 a[i] 的火柴原始位置为 i
        pos[a[i]]=i;
    }

    // 读入第二列火柴并离散化
    c.clear();
    for(int i=1;i<=n;i++){
        cin>>b[i];
        c.push_back(b[i]);
    }
    sort(all(c));
    c.erase(unique(all(c)),c.end());
    for(int i=1;i<=n;i++){
        // 将 b[i] 映射为它在所有数中的排名（从 1 开始）
        b[i]=lower_bound(all(c),b[i])-c.begin()+1;
    }

    // 构造数组 a（覆盖原来的 a）：a[i] = 第一列中排名为 b[i] 的火柴原位置
    // 这样 a 数组就是一个排列，我们需要求它的逆序对数
    for(int i=1;i<=n;i++){
        a[i]=pos[b[i]];
    }

    // 从右向左扫描，用树状数组求逆序对
    int ans=0;
    for(int i=n;i>=1;i--){
        // 查询当前比 a[i] 小的数字个数（即已经在树状数组中的、位于 a[i] 右侧且比它小的数）
        ans = (ans + get(a[i])) % mod;
        // 将 a[i] 加入树状数组
        add(a[i],1);
    }
    cout << ans % mod;
}

signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int T=1;
    //cin>>T;
    while(T--) solve();
    return 0;
}
```

## 复杂度分析

- 离散化：$O(n \log n)$
- 树状数组求逆序对：$O(n \log n)$
- 总时间复杂度：$O(n \log n)$
- 空间复杂度：$O(n)$

## 注意事项

1. 题目要求输出最小交换次数对 $10^8-3$ 取模，代码中在累加答案时进行了取模。
2. 树状数组中的计数不需要取模，因为最大只有 $n \le 10^5$。
3. 两列火柴内部高度互不相同，但两列之间可能有相同高度，因此需要分别离散化。
