# 洛谷 P1593 约数之和（A^B mod 9901）题解

## 题目简介

**链接**：[洛谷P1593](https://www.luogu.com.cn/problem/P1593)

给定两个正整数 **A、B**，求 **A^B** 的所有正约数之和，结果对 **9901** 取模。

是非常经典的**质因数分解 + 等比数列求和 + 快速幂 + 费马逆元**模板题。

## 数学原理

### 1. 质因数分解

任意正整数可以拆分为质因子幂次乘积：

$$A = p_1^{c_1} \cdot p_2^{c_2} \dots p_k^{c_k}$$

那么：

$$A^B = p_1^{c_1B} \cdot p_2^{c_2B} \dots p_k^{c_kB}$$

### 2. 约数和公式

一个数的所有约数和为各质因子等比数列乘积：

$$sum = \prod_{i=1}^k (1+p_i+p_i^2+\dots+p_i^{c_iB})$$

### 3. 等比数列求和取模

等比数列求和公式：

$$S = \frac{p^{k+1}-1}{p-1} \pmod{9901}$$

因为 9901 是质数，可以用**费马小定理求逆元**。

### ✅ 关键特判（本题最大坑点）

若 $p \bmod 9901 = 1$，则分母 $p-1 \equiv 0 \pmod{9901}$，无逆元

此时等比和直接为：

$$S = k+1$$

### 4. 核心原理推导：为什么结果是 $k+1$？

我们常规的等比数列求和公式：$S=\dfrac{p^{k+1}-1}{p-1}$，仅在 $p\neq1$ 时成立。

当满足特判条件 $p \equiv 1 \pmod{9901}$ 时，代表在模 $9901$ 意义下：$p=1$，此时原分式公式分母 $p-1=0$，公式失效，无法用逆元计算。

我们直接代入等比数列原始展开式计算：

$$S=1+p+p^2+p^3+\dots+p^k$$

将 $p\equiv1 \pmod{9901}$代入，所有 $p^n \equiv1^n=1$：

$$S=\underbrace{1+1+1+\dots+1}_{k+1项}$$

数列从 $p^0$ 到 $p^k$ 一共包含 **k\+1 项**，因此最终求和结果为：

$$S \equiv k+1 \pmod{9901}$$

## AC 代码（可直接提交）

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define all(x) x.begin(),x.end()
#define YES cout<<"YES\n"
#define NO cout<<"NO\n"
#define cfs cout<<fixed<<setprecision
typedef pair<int,int> PII;
const int N=5e7+10;
const int mod=9901;
int fac[N];
int cnt[N];
int m=0;

//快速幂
int qpow(int b,int p){
    int ans=1;
    while(p){
        if(p&1){
            ans=ans*b%mod;
        }
        b=b*b%mod;
        p>>=1;
    }
    return ans;
}
int a,b;

//质因数分解
void factor(int x){
    for(int i=2;i*i<=x;i++){
        if(x%i==0){
            fac[++m]=i;
            while(x%i==0){
                x/=i;
                cnt[i]++;
            }
        }
    }
    if(x>1){
        fac[++m]=x;
        cnt[x]++;
    }
    //指数乘B，得到A^B的质因子幂次
    for(int i=1;i<=m;i++){
        cnt[fac[i]]*=b;
    }
}

//费马小定理求逆元
int inv(int x){
    return qpow(x,mod-2)%mod;
}

void solve(){
    cin>>a>>b;
    factor(a);
    int ans=1;
    for(int i=1;i<=m;i++){
        //特判：p ≡ 1 mod 9901，等比和 = 项数
        if((fac[i]-1)%mod==0){
            ans=ans*(1+cnt[fac[i]])%mod;
        }else{
            //等比数列求和公式
            ans=ans*(qpow(fac[i],cnt[fac[i]]+1)-1+mod)%mod*inv(fac[i]-1)%mod;
        }
    }
    cout<<ans;
}

signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int T=1;
    //cin>>T;
    while(T--) solve();
    return 0;
}

```

## 易错点总结

1. **必须特判 p≡1(mod 9901)**：否则测试点 `217823 1` 会输出 0。

2. **减法取模要 +mod**：防止负数导致答案错误。

3. **质因子幂次要乘 B**：求的是 A^B 的约数和。
