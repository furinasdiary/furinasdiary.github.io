# 洛谷 P1835 素数密度 题解


## 题目简介

题目：给定区间 $[L, R]$，求出区间内素数的个数。

链接 ：[P1835](https://www.luogu.com.cn/problem/P1835)

数据范围：

$(1 \le L \le R \lt 2^{31},\quad R-L \le 10^6)$

本题难点：R 极大，无法直接筛 $1\sim R$，需要使用**分段素数筛（区间筛）**。

## 算法思路

1. **预处理小素数**
一个合数 x 一定存在不大于 $\sqrt x$ 的质因子。
先筛出 $\sqrt{2^{31}} \approx 5\times 10^4$ 以内的所有素数。
2. **区间映射**
开数组 `vis[]`，`vis[i]` 表示数值 $L+i$ 是否为合数。
将超大区间压缩到 $[0,R-L]$，解决空间不足问题。
3. **批量标记合数**
对每个预处理出的素数 p，找到 $[L,R]$ 中 p 的倍数并标记为合数。
4. **统计素数**
未被标记的即为素数，注意 1 不是素数。

## AC 代码

```
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int N=1e6+10;

int prime[N];    // 存储筛出的小素数
int isprime[N];  // 欧拉筛标记数组
bool vis[N];     // 偏移数组，vis[i]对应数值 l+i

void solve(){
    int l,r;
    cin>>l>>r;

    // 欧拉筛：预处理 sqrt(R) 内所有素数
    for(int i=2;i<N;i++) isprime[i]=1;
    int m=0;
    for(int i=2;i<N;i++){
        if(isprime[i]) prime[++m]=i;
        for(int j=1;j<=m&&i*prime[j]<N;j++){
            isprime[i*prime[j]]=0;
            if(i%prime[j]==0) break;
        }
    }

    // 分段筛，标记区间合数
    for(int i=1;i<=m;i++){
        int p=prime[i];
        int first=(l+p-1)/p*p; // 整数向上取整，找到区间内第一个p的倍数
        int start=max(p*2,first); // 起点至少2p，不标记素数p本身
        for(int j=start;j<=r;j+=p){
            if(j-l>=0) vis[j-l]=1;
        }
    }

    if(l==1) vis[0]=1; // 1不是素数，特殊标记
    int ans=0;
    for(int i=0;i<=r-l;i++){
        if(!vis[i]) ans++;
    }
    cout<<ans;
}

signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int T=1;
    //cin>>T;
    while(T--) solve();
    return 0;
}

```

## 核心细节讲解

### 1. 为什么可以分段筛

大数无法开数组，但区间长度最大只有 $10^6$，可以偏移存储。
所有合数一定能被小于 $\sqrt R$ 的素数筛掉。

### 2. 筛数起点

```
int start = max(p*2, ceil(l/p)*p);
```

- `ceil(l/p)*p`：区间中第一个大于等于 L 的 p 倍数
- `p*2`：不能把素数本身筛掉

### 3. 偏移数组

`vis[j-l]`
将 $L\sim R$ 映射为 $0\sim R-L$，完美解决空间问题。

## 易错点

1. 数值极大，**必须开 long long**，否则乘法溢出
2. 1 不是素数，需要特判
3. 筛数起点不能是 p，否则会误筛素数
4. 数组大小必须开够，适配 $R-L\le 10^6$

## 复杂度

- 小素数欧拉筛：$O(\sqrt R)$
- 区间筛：接近线性
完全满足题目时限
