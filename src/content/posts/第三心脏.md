# 洛谷 P12336 第三心脏题解（构造题）

链接：[洛谷P12336](https://www.luogu.com.cn/problem/P12336)

## 一、题目描述

给定正整数 $a$，构造正整数四元组 $(a,b,c,d)$，满足：

$$
a^2+b^2+c^2+d^2 = a\oplus b\oplus c\oplus d
$$

且

$$
a<b<c<d<2^{63}
$$

无解输出 $-1$。本题只需输出任意一组合法解。

---

## 二、核心思路

### 2.1 关键构造

令

$$
a\oplus b\oplus c = 1
$$

那么异或和变为：

$$
a\oplus b\oplus c\oplus d = 1\oplus d
$$

如果 $d$ 是偶数，则 $d$ 的二进制最低位为 $0$，于是

$$
d\oplus 1 = d+1
$$

原方程就变成了：

$$
a^2+b^2+c^2+d^2 = (d+1)^2
$$

展开右边：

$$
a^2+b^2+c^2+d^2 = d^2+2d+1
$$

消去 $d^2$，得到：

$$
a^2+b^2+c^2 = 2d+1
$$

所以

$$
d = \frac{a^2+b^2+c^2-1}{2}
$$

只要保证 $a^2+b^2+c^2$ 是奇数，$d$ 就是整数；并且可以证明这样得到的 $d$ 一定是偶数，从而 $d\oplus 1=d+1$ 成立。

于是问题转化为：**构造 $b,c$，使得 $a\oplus b\oplus c=1$，并且 $a,b,c$ 中恰有一个是奇数。**

### 2.2 奇偶性分析

平方数模 $4$ 的性质：

- 偶数平方 $\equiv 0 \pmod 4$
- 奇数平方 $\equiv 1 \pmod 4$

因此 $a^2+b^2+c^2$ 为奇数当且仅当 $a,b,c$ 中恰有一个是奇数。

我们希望构造的 $b,c$ 满足这个条件。

---

## 三、构造方法

### 3.1 选取 $b$

设 $x$ 是最小的整数使得

$$
2^x > a
$$

即 $x = \lfloor \log_2 a \rfloor + 1$。因为 $a\ge 1$，所以 $x\ge 1$。

令

$$
b = 2^x
$$

显然 $b>a$，且 $b$ 是偶数。

### 3.2 选取 $c$

令

$$
c = a\oplus b\oplus 1 = a\oplus 2^x\oplus 1
$$

由于 $2^x > a$，所以 $a$ 与 $2^x$ 的二进制位没有重叠，因此

$$
a\oplus 2^x = a+2^x
$$

于是

$$
c = (a+2^x)\oplus 1
$$


### 3.3 确定 $a,b,c$ 的奇偶性

由构造方法，我们取
$$
b = 2^x > a
$$
因为 $x \ge 1$（当 $a \ge 2$ 时），所以 **$b$ 一定是偶数**，即
$$
b^2 \equiv 0 \pmod 4
$$

接下来讨论 $a$ 的奇偶性：

#### 情况一：$a$ 为奇数

- $a^2 \equiv 1 \pmod 4$
- $b$ 为偶数，故 $b^2 \equiv 0 \pmod 4$
- 因为 $a$ 奇、$b$ 偶，所以 $a \oplus b$ 是奇数；再异或 $1$（奇数），得到 $c = a \oplus b \oplus 1$ 一定是**偶数**。
- 于是 $c^2 \equiv 0 \pmod 4$

计算 $a^2+b^2+c^2$ 模 $4$：
$$
a^2+b^2+c^2 \equiv 1 + 0 + 0 \equiv 1 \pmod 4
$$

所以
$$
a^2+b^2+c^2-1 \equiv 1-1 \equiv 0 \pmod 4
$$

#### 情况二：$a$ 为偶数

- $a^2 \equiv 0 \pmod 4$
- $b$ 为偶数，故 $b^2 \equiv 0 \pmod 4$
- 因为 $a$ 偶、$b$ 偶，所以 $a \oplus b$ 是偶数；再异或 $1$（奇数），得到 $c = a \oplus b \oplus 1$ 一定是**奇数**。
- 于是 $c^2 \equiv 1 \pmod 4$

计算 $a^2+b^2+c^2$ 模 $4$：
$$
a^2+b^2+c^2 \equiv 0 + 0 + 1 \equiv 1 \pmod 4
$$

所以
$$
a^2+b^2+c^2-1 \equiv 1-1 \equiv 0 \pmod 4
$$

### 3.4 结论

无论 $a$ 是奇数还是偶数，都有
$$
a^2+b^2+c^2-1 \equiv 0 \pmod 4
$$
因此 $a^2+b^2+c^2$ 一定是奇数，且
$$
d = \frac{a^2+b^2+c^2-1}{2}
$$
是一个偶数。从而 $d \oplus 1 = d+1$，原方程
$$
a^2+b^2+c^2+d^2 = a\oplus b\oplus c\oplus d
$$
成立。

### 3.5 计算 $d$

$$
d = \frac{a^2+b^2+c^2-1}{2}
$$

因为 $a^2+b^2+c^2$ 是奇数，所以 $d$ 是整数。进一步，由于 $a^2+b^2+c^2 \equiv 1 \pmod 4$，所以 $d = \frac{a^2+b^2+c^2-1}{2}$ 是偶数。

因此 $d\oplus 1 = d+1$，原方程成立。

### 3.6 验证大小关系

- $b = 2^x > a$，显然。
- 若 $a$ 为奇数：$c = a+2^x-1 > 2^x = b$（因为 $a\ge 3$ 时 $a-1>0$；$a=1$ 单独处理）。
- 若 $a$ 为偶数：$c = a+2^x+1 > 2^x = b$。

所以 $a<b<c$。

关于 $d>c$：因为 $d \sim \frac{a^2+b^2+c^2}{2}$，而 $c$ 至多是 $a+b$ 量级，所以 $d$ 远大于 $c$，满足 $c<d$。

### 3.7 特殊情况 $a=1$

当 $a=1$ 时，上述构造会得到 $b=2,\ c=2$，不满足严格递增。直接输出一组特解：

$$
(4,\ 28,\ 40)
$$

## 四、代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define all(x) x.begin(),x.end()
#define YES cout<<"YES\n"
#define NO cout<<"NO\n"
#define cfs cout<<fixed<<setprecision
typedef pair<int,int> PII;
const int N=2e5+10;
const int INF=LONG_LONG_MAX;

void solve(){
    int a;
    cin>>a;
    if(a==1){
        cout<<"4 28 40";
        return;
    }
    int x=0;
    while((1LL<<x)<=a) x++;
    int b=1LL<<x;
    int c=a^b^1;
    int d=(a*a+b*b+c*c-1)/2;
    cout<<b<<' '<<c<<' '<<d;

}
signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int T=1;
    //cin>>T;
    while(T--) solve();
    return 0;
}
```
## 五、另一种构造方式
```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define all(x) x.begin(),x.end()
#define YES cout<<"YES\n"
#define NO cout<<"NO\n"

void solve(){
    int a;
    cin>>a;
    if(a==1){
        cout<<"4 28 40";
        return;
    }
    int x=0;
    while((1LL<<x)<=a) x++;
    int b=(1LL<<x)+a;
    int c=a^b^1;
    if(a%2){
		b--;
		c--;
	}
	int d=(a*a+b*b+c*c)/2;
	if(b>c) swap(b,c);
	cout<<b<<" "<<c<<" "<<d;

}
signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int T=1;
    //cin>>T;
    while(T--) solve();
    return 0;
}
```
