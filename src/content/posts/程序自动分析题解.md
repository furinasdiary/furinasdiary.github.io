# 洛谷 P1955 程序自动分析题解（离散化 + 并查集）
## 题目简介
题目链接：[洛谷P1955](https://www.luogu.com.cn/problem/P1955)

难度：普及+/提高，并查集经典题，同时考察离散化。

给定若干变量约束：$x_i=x_j$ 或者 $x_i \neq x_j$，判断所有约束条件能否同时成立。多组数据，每组独立，输出 YES / NO。

## 解题思路
### 1. 核心：并查集
相等关系具有传递性：
$x_1=x_2,x_2=x_3 \Rightarrow x_1=x_3$，完美匹配并查集的连通模型。
- $e=1$：$x_i=x_j$，合并两个变量所在的集合。
- $e=0$：$x_i \neq x_j$，要求两个变量不在同一个连通集合。

### 2. 难点：变量编号值域极大
题目中变量编号 $i,j \le 10^9$，无法直接开数组存储。
但是约束最多只有 $10^5$ 组，出现的变量最多 $2\times10^5$ 个。
所以使用**离散化**，把巨大的编号映射成连续的小下标。

### 3. 解题步骤
1. 读入全部约束，收集所有出现的变量编号。
2. 对收集到的变量排序、去重，完成离散化映射。
3. 优先处理所有相等约束（$e=1$），合并连通块。
4. 再校验不等约束（$e=0$）：如果两个变量已经在同一个集合，说明矛盾，答案为 NO。
5. 全部约束校验通过则输出 YES。

## AC代码
```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define all(x) x.begin(),x.end()
#define YES cout<<"YES\n"
#define NO cout<<"NO\n"
#define cfs cout<<fixed<<setprecision
typedef pair<int,int> PII;
const int N=2e5+10;
const int INF=1e18;

// 并查集数组
int p[N];

// 存储每条约束：i j e
struct node
{
    int i,j,e;
};

// 并查集找根（路径压缩）
int find(int x){
    if(p[x]!=x) p[x]=find(p[x]);
    return p[x];
}

// 合并两个集合
void merge(int x,int y){
    int rx=find(x),ry=find(y);
    if(rx!=ry) p[rx]=ry;
}

void solve(){
    // 初始化并查集
    for(int i=1;i<N;i++) p[i]=i;

    int n;
    cin>>n;
    vector<node> a(n+1);
    vector<int> b; // 存放所有出现的变量，用于离散化

    // 读入所有约束
    for(int i=1;i<=n;i++){
        cin>>a[i].i>>a[i].j>>a[i].e;
        b.push_back(a[i].i);
        b.push_back(a[i].j);
    }

    // 离散化：排序去重
    sort(all(b));
    b.erase(unique(all(b)),b.end());

    // 将原大数映射为连续小下标
    for(int i=1;i<=n;i++){
        a[i].i=lower_bound(all(b),a[i].i)-b.begin()+1;
        a[i].j=lower_bound(all(b),a[i].j)-b.begin()+1;
    }

    // 排序：优先处理相等约束 e=1
    sort(a.begin()+1,a.end(),[](node x,node y){
        return x.e>y.e;
    });

    // 逐条判断
    for(int i=1;i<=n;i++){
        int x=a[i].i;
        int y=a[i].j;
        int op=a[i].e;

        if(op==1){
            // 相等：合并集合
            merge(x,y);
        }else{
            // 不等：若已连通，矛盾
            if(find(x)==find(y)){
                NO;
                return;
            }
        }
    }
    // 全部合法
    YES;
}

signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int T=1;
    cin>>T;
    while(T--) solve();
    return 0;
}
