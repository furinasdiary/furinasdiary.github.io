# 区间欧拉函数求和 | 签到题 题解

链接：[洛谷P3601](https://www.luogu.com.cn/problem/P3601)

## 题目描述
定义函数：
$$\text{qiandao}(x)$$
为小于等于 $x$、且与 $x$ **不互质**的数的个数。

给定区间 $[l,r]$，求：
$$\sum_{i=l}^{r} \text{qiandao}(i) \bmod 666623333$$

## 解题思路
根据欧拉函数定义：
$\varphi(x)$ 表示 $1\sim x$ 中与 $x$ **互质**的数的个数。

可以直接得到公式：
$$\text{qiandao}(x) = x - \varphi(x)$$

题目转化为：
$$\sum_{i=l}^r (i-\varphi(i)) \bmod 666623333$$

### 算法选择
$l,r$ 可到 $10^{12}$，无法直接筛全范围。
但题目保证 $r-l \le 10^6$，可以使用：
**分段筛（区间筛）求区间欧拉函数**

## 算法流程
1. 欧拉筛预处理 $\sqrt{r}$ 以内所有素数
2. 偏移数组初始化：`phi[i-l] = i`，`val[i-l] = i`
3. 用每个素数更新区间内数字的欧拉函数
4. 处理剩余的大质因子
5. 累加答案取模

## AC代码
```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int N=1e6+10;
const int mod=666623333;

int prime[N];
bool isprime[N];
int phi[N];
int val[N];

void solve(){
    int l,r;
    cin>>l>>r;

    // 欧拉筛预处理小素数
    memset(isprime,1,sizeof(isprime));
    int m=0;
    for(int i=2;i<N;i++){
        if(isprime[i]) prime[++m]=i;
        for(int j=1;j<=m&&i*prime[j]<N;j++){
            isprime[i*prime[j]]=0;
            if(i%prime[j]==0) break;
        }
    }

    // 区间偏移初始化
    for(int i=l;i<=r;i++){
        phi[i-l]=val[i-l]=i;
    }

    // 分段筛更新欧拉函数
    for(int i=1;i<=m;i++){
        int p=prime[i];
        int start=(l+p-1)/p*p;
        for(int j=start;j<=r;j+=p){
            phi[j-l]=phi[j-l]/p*(p-1);
            while(val[j-l]%p==0) val[j-l]/=p;
        }
    }

    // 处理剩余大质因子
    for(int i=l;i<=r;i++){
        if(val[i-l]>1)
            phi[i-l]=phi[i-l]/val[i-l]*(val[i-l]-1);
    }

    // 统计答案
    int ans=0;
    for(int i=l;i<=r;i++){
        ans=(ans+i-phi[i-l]+mod)%mod;
    }
    cout<<ans;
}

signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    solve();
    return 0;
}
```
