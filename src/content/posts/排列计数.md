# 洛谷 P4071 排列计数 题解

题目链接：[洛谷P4071](https://www.luogu.com.cn/problem/P4071)

## 题目大意

给定多组 $n,m$，求有多少个 $1\sim n$ 的排列 $a$，满足恰好有 $m$ 个位置 $i$ 使得 $a_i=i$。

答案对 $10^9+7$ 取模。

---

## 思路

恰好有 $m$ 个位置满足 $a_i=i$，可以分两步计数：

1. 从 $n$ 个位置中选出 $m$ 个位置，强制它们满足 $a_i=i$。  
   方案数为：
   $$
   \binom{n}{m}
   $$

2. 剩下的 $n-m$ 个位置不能再有 $a_i=i$，也就是这 $n-m$ 个元素必须全部错排。  
   设 $D_k$ 表示 $k$ 个元素的错排数，则方案数为：
   $$
   D_{n-m}
   $$

所以答案为：
$$
\boxed{\binom{n}{m}\times D_{n-m}\bmod (10^9+7)}
$$

错排递推公式：
$$
D_0=1,\quad D_1=0,\quad D_2=1
$$
$$
D_i=(i-1)(D_{i-1}+D_{i-2})
$$

递推公式证明：把第 $i$ 个元素放到某个位置 $p$，有 $i-1$ 种选择。  
如果位置 $p$ 对应的元素放到了位置 $i$，则剩下 $i-2$ 个元素错排；  
否则，相当于剩下 $i-1$ 个元素错排。

因此我们只需要预处理：

- 阶乘 $fact[i]$
- 阶乘逆元 $invfact[i]$
- 错排数 $D[i]$

之后每组询问可以 $O(1)$ 回答。

## 代码实现

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define all(x) x.begin(),x.end()
#define YES cout<<"YES\n"
#define NO cout<<"NO\n"
#define cfs cout<<fixed<<setprecision
typedef pair<int,int>PII;
const int N=1e6+10;
const int INF=1e18;
const int mod=1e9+7;

int fact[N];   // 阶乘
int infact[N]; // 阶乘逆元
int f[N];      // 错排数

int ksm(int x,int y){  // 快速幂
    int ans=1;
    while(y){
        if(y&1){
            ans=ans*x%mod;
        }
        x=x*x%mod;
        y=y>>1;
    }
    return ans;
}
void init(){  // 预处理
    fact[0]=1;
    for(int i=1;i<N;i++){
        fact[i]=fact[i-1]*i%mod;
    }
    infact[N-1]=ksm(fact[N-1],mod-2);  // 费马小定理求逆元
    for(int i=N-2;i>=0;i--){
        infact[i]=infact[i+1]*(i+1)%mod;
    }
    f[0]=1,f[1]=0,f[2]=1;  // 错排初始值
    for(int i=3;i<N;i++){
        f[i]=(i-1)*(f[i-1]%mod+f[i-2]%mod)%mod;  // 错排递推
    }
}
int c(int n,int m){  // 组合数 C(n,m)
    return fact[n]*infact[n-m]%mod*infact[m]%mod;
}
void solve(){
    int n,m;
    cin>>n>>m;
    cout<<c(n,m)*f[n-m]%mod<<'\n';  // 答案 = C(n,m) * D(n-m)
}
signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int T=1;
    init();  // 预处理
    cin>>T;
    while(T--) solve();
    return 0;
}
```

## 复杂度分析

- 预处理时间复杂度：$O(N)$，其中 $N=10^6$
- 单组询问时间复杂度：$O(1)$
- 总时间复杂度：$O(N+T)$
- 空间复杂度：$O(N)$
