# 欧拉筛（线性素数筛）模板题解
## 算法介绍
欧拉筛是时间复杂度为 **O(n)** 的线性素数筛。
相比埃氏筛，每个合数**只会被最小质因子筛一次**，效率更高，适合大范围素数预处理。

## 核心原理
1. 初始化所有数为素数
2. 遍历每个数，若是素数则加入素数数组
3. 枚举已存素数，标记 `i * prime[j]` 为合数
4. 当 `i % prime[j] == 0` 立刻 break，保证每个合数只被筛一次

##  代码
```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int N=1e7;

bool isprime[N]; // 是否为素数
int prime[N];    // 存储所有素数

signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    
    int n;
    cin>>n;

    // 初始化：默认全部是素数
    for(int i=2;i<=n;i++) isprime[i]=1;

    int cnt=0;
    for(int i=2;i<=n;i++){
        // 是素数则存入数组
        if(isprime[i]) prime[++cnt]=i;
        // 枚举素数进行筛除
        for(int j=1;j<=cnt&&prime[j]*i<=n;j++){
            isprime[prime[j]*i]=0;
            // 遇到最小质因子，停止筛
            if(i%prime[j]==0) break;
        }
    }

    // 输出所有素数
    for(int i=1;i<=cnt;i++){
        cout<<prime[i]<<" ";
    }
    return 0;
}
