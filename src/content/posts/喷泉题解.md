# 洛谷P7167 Fountain 题解

链接：[洛谷P7187](https://www.luogu.com.cn/problem/P7167)

## 题目大意

有 $n$ 块石头，位置严格递增：$p_1 < p_2 < \cdots < p_n$。  
一只青蛙从某块石头出发，每次跳到距离当前石头第 $k$ 近的石头上。  
若第 $k$ 近的石头不唯一（距离相等），则选择位置更靠前（距离源头更近）的那块。  
对于每块石头，求从它出发连续跳 $m$ 次后所在的石头编号。

数据范围：  
$1 \le k < n \le 10^6$，$1 \le m \le 10^{18}$，$1 \le p_i \le 10^{18}$。

---

## 思路

### 1. 预处理单次跳跃位置

对于每块石头 $i$，需要找到距离它第 $k$ 近的石头。  
由于石头位置有序，可以用**双指针**维护一个长度为 $k+1$ 的窗口 $[l, r]$，其中包含石头 $i$。  
窗口内除 $i$ 外恰好有 $k$ 块石头，因此第 $k$ 近的石头就是窗口两端 $l$ 和 $r$ 中距离 $i$ 更远的那一块。

具体地，从左到右枚举 $i$，维护 $l=1,\ r=k+1$。  
当右边下一块石头比左边当前石头更近时，窗口整体右移：

$$
r+1 \le n \ \text{且} \ p_{r+1}-p_i < p_i-p_l
\ \Longrightarrow\ l \leftarrow l+1,\ r \leftarrow r+1
$$

然后比较两端距离：

- 若 $p_i-p_l \ge p_r-p_i$，则选择 $l$；
- 否则选择 $r$。

这样得到的 $t_i$ 就是石头 $i$ 一次跳跃后的位置。

---

### 2. 快速幂模拟多次跳跃

$m$ 最大可达 $10^{18}$，直接模拟会超时。  
注意到每次跳跃都是确定的函数 $t: \{1,\dots,n\} \to \{1,\dots,n\}$，可以用**二进制快速幂**（倍增）计算 $t^m(i)$。

维护：

- `ans[i]`：当前已经累积跳跃后所在的位置，初始为 $i$；
- `t[i]`：当前代表的跳跃函数，初始为单次跳跃；
- 指数 `x = m`。

当 `x` 的二进制某一位为 $1$ 时，把 `ans` 再复合一次 `t`：

$$
ans[i] \leftarrow t[ans[i]]
$$

然后令 `t` 自平方：

$$
t[i] \leftarrow t[t[i]]
$$

并将 `x` 右移一位。循环直到 `x = 0`。

最终 `ans[i]` 即为从石头 $i$ 出发跳 $m$ 次后的位置。

---

## 复杂度分析

- 双指针预处理单次跳跃：$O(n)$
- 快速幂处理 $m$ 次跳跃：$O(n \log m)$
- 总时间复杂度：$O(n \log m)$
- 空间复杂度：$O(n)$

对于 $n \le 10^6$，$\log m \approx 60$，总操作量约 $6 \times 10^7$，可以在时限内通过。

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define all(x) x.begin(),x.end()
#define YES cout<<"YES\n"
#define NO cout<<"NO\n"
#define cfs cout<<fixed<<setprecision
typedef pair<int,int> PII;
const int N=1e6+1;

int a[N];
int t[N];
int st[N];
int ans[N];

void solve(){
    int n,k,m;
    cin>>n>>k>>m;
    for(int i=1;i<=n;i++){
        cin>>a[i];
        ans[i]=i;
    }

    // 双指针预处理单次跳跃位置
    int l=1,r=k+1;
    for(int i=1;i<=n;i++){
        while(r+1<=n && a[r+1]-a[i] < a[i]-a[l]){
            l++;
            r++;
        }
        if(a[i]-a[l] >= a[r]-a[i]) t[i]=l;
        else t[i]=r;
    }

    // 二进制快速幂模拟 m 次跳跃
    int x=m;
    while(x){
        if(x&1){
            for(int i=1;i<=n;i++){
                ans[i]=t[ans[i]];
            }
        }
        for(int i=1;i<=n;i++){
            st[i]=t[t[i]];
        }
        for(int i=1;i<=n;i++){
            t[i]=st[i];
        }
        x>>=1;
    }

    for(int i=1;i<=n;i++) cout<<ans[i]<<" ";
}

signed main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    int T=1;
    //cin>>T;
    while(T--) solve();
    return 0;
}
```
